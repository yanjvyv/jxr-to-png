# JXR → PNG 自动转换工具（可一键部署）

监视你指定的文件夹（含所有子文件夹），发现 `.jxr` 图片就自动转成 `.png`，
转换后做**像素级比对**验证——通过才删除 JXR 原图；不通过则删除刚生成的 PNG、保留原图，
并把文件改名 `<原名>.not.jxr` 防死循环。工具以**隐藏计划任务**在登录时静默后台运行，
无窗口、无打扰。纯 PowerShell 实现，**无需安装任何依赖**（用系统自带 WPF/WIC 图像组件）。

## 环境要求

- Windows 10 / 11（自带的 .NET + 图像组件即可）
- Windows PowerShell 5.1（系统自带，无需额外安装）

## 一键部署（3 步）

1. **下载**：本仓库 `Code ▾ → Download ZIP`，解压到任意英文或无空格目录，例如 `C:\jxr2png\`（支持中文目录，但建议别放带空格的路径）；
2. **安装**：在该文件夹里打开 PowerShell，运行：
   ```powershell
   .\install.ps1
   ```
   按提示输入要监视的文件夹（例如 `D:\截图`），回车；
3. **确认 UAC**：脚本会自动请求管理员权限注册计划任务，点「是」即可。

完成。之后把任何 `.jxr` 放进被监视文件夹，几秒内就会被自动转成 `.png`（原 JXR 通过校验后删除）。

> 无人值守/脚本化安装（不弹交互）：
> ```powershell
> .\install.ps1 -ScanRoot "D:\截图" -IntervalSec 15 -MaxRetry 4
> ```

## 配置文件（自动生成，可手改）

安装后脚本目录里会生成 `config.json`：

```json
{
  "ScanRoot": "D:\\截图",   // 要监视的文件夹（递归）
  "IntervalSec": 15,         // 轮询间隔（秒）
  "MaxRetry": 4              // 解码失败连续几次后打 .not 标记
}
```

改完需要重启 watcher 才生效：运行 `uninstall.ps1` 后再跑一次 `install.ps1`，或重启电脑。

## 工作原理

对每个 JXR 文件：

1. 用 WPF/WIC 解码 JXR，在同一目录写出同名 `.png`；
2. 重新解码 PNG 与 JXR 逐像素比对（先 SHA-256 快路径，不一致再全量逐像素扫描）；
3. **比对通过**（阈值内）→ 删除 JXR，保留 PNG；
4. **比对不通过** → 删除刚生成的 PNG、保留 JXR，改名 `<原名>.not.jxr`（此后永久跳过，不会循环）；
5. 解码失败（文件被占用/拷贝未完成/损坏）**跨轮重试**默认 4 次后打 not 标记，避免把正在写入的临时文件误判为坏文件。

比对阈值：单通道最大差 ≤ 12、平均差 ≤ 1.5、坏像素占比 ≤ 0.05%。
PNG 由 JXR 解码结果无损写出，正常转换实测为**逐字节一致（差异 0）**；
阈值只为容忍极端编码器舍入误差，任何真实损坏都会导致比对失败并保留原图。

## 常用操作

| 操作 | 命令 |
|---|---|
| 卸载（停进程、删自启） | `.\uninstall.ps1`（无需管理员） |
| 只跑一遍测试（不动自启） | `.\JxrToPng.ps1 -ScanRoot D:\截图 -Once` |
| 自测（合成样本，全自动） | `.\SelfTest.ps1` |
| 自测（额外用真实 JXR 样本） | `.\SelfTest.ps1 -RealJxr "D:\某张图.jxr"` |
| 看运行日志 | 脚本目录下 `JxrToPng.log`（超 2 MB 自动截尾留 600 行） |

> 自测会使用同一份 `JxrToPng.log`，`SelfTest.ps1` 内部已带 `-SkipMutex`，
> watcher 运行中也可直接执行；日志行互相穿插不影响文件级断言结果。

| 文件 | 作用 |

## 已知限制（如实说明）

- 「开机自启」= **用户登录时触发**（与启动文件夹语义相同）。如需登录前（锁屏/未登录）转换，需另配 SYSTEM 级任务，本工具未做。
- 打上 `.not.jxr` 的文件**永久跳过**；若系误判，把文件名里的 `.not` 删掉，下一轮会重试。
- 文件正被其它程序写入（如同步盘）时会按重试策略等待，不会误删。
- 目录被移动/改名后需重跑 `install.ps1`（配置与任务都会重建）。
- 多个 watcher 同时跑会被单实例互斥挡住，不会并发处理同一文件。
- JXR 体积小但 PNG 通常大 2–5 倍，请留意磁盘空间。
